# Реестр рисков

## Обозначения:
*   **Вероятность (L):** 1 (Низкая), 2 (Средняя), 3 (Высокая)
*   **Воздействие (I):** 1 (Низкое), 2 (Среднее), 3 (Высокое), 4 (Критическое)
*   **Уровень риска:** L * I (до 12 баллов)
*   **Стратегия:** Снизить (Mitigate), Принять (Accept), Передать (Transfer), Избежать (Avoid)
