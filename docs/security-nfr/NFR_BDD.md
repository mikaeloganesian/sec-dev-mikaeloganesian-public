Feature: **NFR-01 Скорость загрузки каталога** \
  Scenario: Время загрузки каталога не превышает 1 секунду \
    Given сервис развернут на тестовом стенде и нагрузка 50 RPS \
    When запускается 5-минутный нагрузочный тест \
    Then p95 времени ответа для GET /api/v1/catalog **≤ 1000 ms**

---

Feature: **NFR-03 Защита от Brute-Force** \
  Scenario: Блокировка IP после превышения лимита неудачных попыток входа (Негативный) \
    Given пользователь с IP 192.168.1.100 пытается войти \
    When пользователь вводит неверный пароль **5 раз за 1 минуту** \
    And пытается войти шестой раз \
    Then система возвращает ошибку **429 "Too Many Requests"** и блокирует IP на 10 минут

---

Feature: **NFR-02 Хеширование паролей** \
  Scenario: Хеширование пароля при регистрации \
    Given новый пользователь вводит пароль "Pa$$word123" \
    When пароль отправляется на сервер для регистрации \
    Then пароль сохраняется в базе данных с использованием алгоритма **Argon2id**

---

Feature: **NFR-08 Отказоустойчивость API** \
  Scenario: Доступность критического API авторизации (Uptime 99.9%) \
    Given сервис авторизации запущен и находится под мониторингом \
    When система мониторинга опрашивает эндпоинт /health каждые 5 минут в течение месяца \
    Then общее время недоступности сервиса за месяц составляет **не более 40 минут**
